ADD TO CALENDAR UPGRADE

Upload everything inside this folder to the ROOT of your existing
south-florida-events-dashboard GitHub repository.

Replace:
- broward.html
- miami.html

Add:
- calendar.js

Also upload/update:
- tests/test_calendar_export.py
- tests/test_dashboard_features.py

What it adds:
- 📅 Add to Calendar button on every event card
- Downloads a standard .ics calendar event
- Uses the event title, date/time, venue, city, category, cost, age info, and ticket/event link
- Events with a specific time get a timed calendar entry
- Events with TBD / Evening / Night / other non-specific times are saved as all-day events
- Events with a listed time range use that range
- Single-time events default to a 2-hour duration
- Overnight ranges roll into the next day

No changes are made to:
- broward-events.json
- miami-events.json
- event schema
- updater/collector workflow

After upload:
1. Commit changes.
2. Wait for GitHub Pages to republish.
3. Refresh both dashboards.
4. Tap 📅 Add to Calendar on a test event.
